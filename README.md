# 🎓 EduGuide AI

EduGuide AI is an AI-powered educational assistant that helps students understand concepts instead of simply giving answers. It generates easy-to-understand explanations, step-by-step solutions, real-life examples, flowcharts, key takeaways, and practice questions using AI.

## 🚀 Live Demo

https://eduguideai-y6wg.onrender.com

## ✨ Features

- 🤖 AI-powered concept explanation
- 📚 Step-by-step learning
- 🌍 Real-life examples
- 📊 Simple flowcharts
- ✅ Key takeaways
- 🎯 Practice questions
- 🌐 Easy-to-use web interface

## 🛠️ Tech Stack

- Python
- Flask
- Groq API (Llama 3.1)
- HTML
- CSS
- JavaScript
- Render (Deployment)
- GitHub
